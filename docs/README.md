# Documentatie

## Voor gebruikers

TCE biedt een zelfstandige sandbox en een optionele koppeling met de officiële Milan-app. De sandbox bevat geen automatische Milan-regels. Bij gekoppeld spelen bepaalt de officiële app regels, verhaal en campagne; volledige campagnes, alle uitbreidingen en installatie op een schone tweede pc zijn nog niet volledig gevalideerd.
