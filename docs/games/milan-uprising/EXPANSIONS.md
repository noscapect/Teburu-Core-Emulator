Inventory follows [Xplored Official Physical Inventory](https://teburu.zendesk.com/hc/en-us/articles/25458904976667-Physical-components-VTM). Names of the four additional characters have also been checked on the [official game page](https://games.teburu.com/vtm-milan-uprising). Only names, numbers and own schematic presentation are included; stories and rules remain in the official app.

Together these are **101 extra parts**, in addition to the 132 parts of the basic game. The check miniatures are alternative physical representations: do not place both a basic check token and a check miniature to double count the same check. The table does not calculate a check from the number of miniatures.

## Operation

The standalone demo offers under **Table settings → Table profile** the profile **Milan · base game + 6 expansion packs**. **Start an empty table with this profile** starts an empty table; first save an existing session. The existing basic profiles remain available for their old exports. In **Stock** you can filter by base game or one of the six packs. All components support regular placement, shared zones, reset, undo/redo, and JSON storage.

The linked table uses the extensive stock. It offers eleven characters, eight allies and seven ghouls as scannable miniatures. Scans are only available when the official app enables its reader; they use their own persistent simulation identities.

For control miniatures, expansion cubes and tokens, under **Stock → Place expansion markers** you will find a component selection, location selection and control for placing or returning to stock. This also works via the shared board link. These actions only change our table: follow the placement instructions in Milan. The automatic influence/control recognition is limited to the three basic factions. Sabbat, Nephilim and special expansion markers are taken over manually. A marker operation cannot move a scannable miniature and rejects an outdated table revision.

Selecting or filtering on our table will not activate an expansion story in the official app. Use the normal expansion choice in Milan for this. No activation codes, official tag identities, campaign content, or modified app files have been added. The Prospero accessory miniature with LED ring remains a separate accessory.

## Sessions and limitations

Save an export before starting an empty table profile. Import requires the appropriate profile and version. The linked adapter can convert custom base board exports to the extended stock while preserving positions and throws; this does not change an official Android save.

Full campaigns of the six expansions and all new miniatures have not yet been validated through actual Android gaming operations. The stock and scan buttons do not prove that compatibility. Sabbat, Nephilim and special expansion markers are taken over manually. All 101 expansion parts have an artwork link; where a large portrait is missing, the detailed view uses the icon.
